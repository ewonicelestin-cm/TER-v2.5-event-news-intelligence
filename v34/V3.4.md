# TER v3.4 — Security, Identity, Persistence & Production Core

## Ajouts
- identités et rôles ADMIN / ANALYST / VIEWER
- sessions à jeton opaque avec hash serveur
- hachage de mots de passe via scrypt
- rate limiting HTTP
- en-têtes de sécurité
- request IDs
- limite de taille JSON
- endpoints auth : register/login/me
- endpoint `/api/security/status`
- schéma PostgreSQL pour utilisateurs, sessions, préférences et audit sécurité
- mode d'authentification optionnel pour conserver le démarrage local simple

## Production
Pour un déploiement réel :
1. définir `AUTH_ENABLED=true`;
2. remplacer les identifiants de démonstration;
3. définir `CORS_ORIGIN` explicitement;
4. utiliser HTTPS derrière un reverse proxy;
5. configurer PostgreSQL et les sauvegardes;
6. ne jamais exposer les clés fournisseurs au navigateur.

Le moteur reste analytique/paper-trading : aucune exécution broker réelle n'est activée par ce module.
