# TER v3.3 — Workflow & Scenario Builder

TER v3.3 ajoute une couche d'orchestration configurable au-dessus des moteurs existants.

## Fonctionnalités
- workflows composés de Trigger, Condition, Logic, Scenario, Journal et Notification ;
- validation du graphe côté API ;
- statuts DRAFT / ACTIVE / PAUSED ;
- exécution en dry-run et trace d'exécution ;
- historique des runs ;
- audit des exécutions ;
- aucune exécution financière réelle ;
- API CRUD complète.

## API
- GET /api/workflows
- GET /api/workflows/stats
- GET /api/workflows/runs?workflowId=...
- POST /api/workflows
- PATCH /api/workflows/:id
- DELETE /api/workflows/:id
- POST /api/workflows/:id/run

## Gouvernance
Les workflows v3.3 sont des outils d'analyse, de simulation, d'alerting et de journalisation. Aucun ordre de marché n'est transmis à un courtier.
