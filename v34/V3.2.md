# TER v3.2 — Alert Rules & Automation Engine

TER v3.2 complète le centre de monitoring avec un moteur de règles déterministe.

## Fonctionnalités
- règles `ALL` / `ANY`
- métriques : score signal, confiance, variation 24h, qualité des données, prix
- opérateurs `>`, `>=`, `<`, `<=`, `=`
- symboles individuels ou univers `*`
- sévérité INFO / MEDIUM / HIGH
- cooldown configurable
- activation/désactivation
- compteur de déclenchements
- génération de notifications dans le cycle de monitoring

## API
- `GET /api/automation/rules`
- `POST /api/automation/rules`
- `PATCH /api/automation/rules/:id`
- `DELETE /api/automation/rules/:id`

Les règles sont en mémoire dans cette version. Aucune exécution réelle d'ordre n'est déclenchée.
